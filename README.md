# Global Animal Disease Surveillance - Open Source Project

Using Open Data Sources, showcase well-curated results of advanced exploratory analysis conducted in Python with an interactive visual dashboard in Tableau.
This Python exercise involved exploring relationships, geographical visualization with Python, supervised machine learning (regression), unsupervised machine learning (clustering) and analyzing time-series data (time-series data is not related to the dataset).

Tableau link available for further dashboard interactions.

**This project was conducting on finding data of personal interested. There was little guidance with questions to answer with the data and insight to be uncovered. This would be a semi-independent project.**
